Importar / Exportar (JSON)

Importa un anime — o varios (arreglo) — desde un archivo .json con la misma estructura de la base de datos (como Black-torch.json). Se cargan al catálogo conservando todos sus campos y episodios.

El Título es el que se muestra. Los alternativos NO se ven en la tarjeta: sirven para que el anime aparezca al buscar por cualquiera de sus nombres (japonés/romaji e internacional). Se auto-rellenaron desde AniList; puedes editarlos.

Agregar episodios

Agrega uno o varios servidores (plustream, streamwish, filemoon, doodstream…). Pega la URL embed de cada uno. El reproductor se genera solo, sin crear archivos. El ícono se detecta por el nombre.

Solo para casos legado: si ya tienes un archivo frame/…/T1/1.html hecho a mano y quieres apuntar a él. Con los servidores de arriba no hace falta: se usa el reproductor genérico frame/player.html (no se crea ningún archivo por episodio).

Importar lista de episodios

Para animes muy extensos (One Piece, etc.). Pega la lista y se crean todos los episodios de una vez en el anime elegido arriba, sin servidores (luego los rellenas con «Subir» o el sanador). Los duplicados (misma temporada + número) se omiten solos. Formatos aceptados:

  • Texto: una línea por episodio — S1E1 - Título, 1. Título, 1 | Título, o solo Título. Una línea suelta Temporada 2: cambia la temporada a partir de ahí.
  • JSON: un arreglo [{"season":"Temporada 1","number":1,"title":"…"}] (acepta también servers, img, releaseDate…).

Con Cargar archivo JSON subes un .json con la lista (mismo formato que exporta). Exportar JSON descarga los episodios del anime elegido (para respaldo o mover a otro anime).

Cola de subida

Al terminar cada subida, el servidor se agrega solo al episodio correspondiente (no sobrescribe: se añade a los que ya tenga).

Notificaciones a usuarios

Publica un mensaje que verán los usuarios como un aviso discreto (toast en la esquina o banner arriba), con auto-cierre. Se muestra una sola vez por envío. Ideal para anuncios, nuevos episodios o mantenimiento.
